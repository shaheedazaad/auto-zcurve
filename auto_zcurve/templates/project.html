What the schema controls

Think of the schema as a blank data table. Each named field becomes a column, and its description tells the LLM what belongs in that column.

meta_data
Information recorded once per article, such as its DOI or study description.
effects
Information repeated for every focal statistical result found in the article.
type
The kind of answer allowed: string, number, integer, boolean, or array.
description
A plain-language instruction explaining what the LLM should extract.
required
Use true only when every response must contain this field.

Keep a reported statistic for z-curve

The analysis needs a field containing a statistic such as t(38)=2.14, F(1,98)=4.10, z=2.41, or p=0.012.

Name that field reported_statistic, or mark a differently named field with:

role: reported_statistic

Without a usable reported statistic, extraction can succeed but there may be nothing to include in the z-curve.

Validation checks

auto-zcurve checks the YAML structure, field definitions, supported types, array item types, duplicate roles, and that effects contains at least one field.

Validation happens before any existing output is deleted.
